# 研究方向总结：组合对抗体系的胜率评估方法（最终定稿版）

## 〇、方向演化史（三段嬗变）

1. **起点（原始文档）**：“多智能体编组对抗态势效能评估”——四层机理架构、禁一切数据驱动、军用叙事。评估结论：定位有真需求，但验证闭环缺失、发表通道错误、就业技能树错配。
2. **导师类比落地**：“王者荣耀 5v5 阵容，看属性判胜率，大量模拟求概率，尽量不数据驱动”——任务从“泛体系评估”收敛为**具体的、可验证的、有民用对标的组合对抗评估问题**。
3. **最终形态**：“不依赖实际交战数据的多智能体体系效能评估”——以游戏阵容为实验场、以机理骨架 + 概率语义 + 模拟校准为方法本体、以可解释评估方法论为就业资产。**场景（军事/游戏）只是皮，方法（无真值评估）才是骨。**

## 一、研究问题定义（最终版）

**给定一个尚未交战的配置（双方 5v5 阵容 / 无人集群编成），在无真实对局数据条件下，输出其相对强弱（带置信区间的胜率）、优势来源归因、以及改进方案（What-if / 优化）。**

形式化：求评估函数 $P(A\text{ 胜 }B) = f(\text{配置}_A,\ \text{配置}_B,\ \text{环境}) \in (0,1)$。

**硬约束**：① 不用实际交战数据训练（导师红线，模拟数据导师明确接受）；② 算力有限（CPU 级 + 消费级 GPU）；③ 研究生一人，时间充裕但无大团队；④ 就业不走军工，技能树必须民用可迁移。

**核心难点（贯穿全文的四个死穴及对策）**：

| 死穴 | 对策 |
| --- | --- |
| 无真实数据 → 无验证闭环 | 模拟器当参照物 + 两层验证体系 |
| 组合空间 ~10¹⁵–10¹⁹ 算不完（C(100,5)²/2 ≈ 2.8×10¹⁵，计入分路约 4×10¹⁹） | 代理模型 + 主动模拟预算分配 |
| 输出无语义（“评分 87 分”是什么） | Bradley-Terry 概率锚 |
| 机理参数拍脑袋 | 模拟校准 + 敏感性分析 |

## 二、确认的主线技术路线（七件套，每件含“为什么”）

### 2.1 结构化评估函数（机理骨架）

**是什么**：三个并联模块汇成一个强度函数 $s(\text{阵容})$：
- **属性建模**：英雄 → 属性向量，**必须含强度时间曲线**（前期/中期/后期）；
- **克制关系建模**：机制类级别的克制规则（真伤克高血量、突进克无位移），通过“机制类 × 属性”自动展开为关系图——**不是逐对填 100×100 矩阵**；
- **集合聚合**：协同增益项（混伤互补、控制链）+ 短板惩罚项（双 C 抢经济、全脆皮）。

**为什么这样设计**：把领域知识写死在模型结构里，而不是让模型从数据里学——这是“无真实数据”约束下唯一可行路线；结构化也换来可解释性（每个分项对应可查的机制，支撑“为什么强、哪里弱”的归因输出）。

**为什么不用兰彻斯特方程聚合（已否决）**：见第三节 E2。

### 2.2 Bradley-Terry / logistic 概率层

**是什么**：机理骨架算出强度差 $s_A - s_B$，logistic 函数把强度差映射成概率：

$$P(A\text{胜}B) \;=\; \sigma(s_A - s_B) \;=\; \frac{1}{1+e^{-(s_A-s_B)}}$$

**为什么用它（数学理由）**：
1. **概率语义四性质**：单调（强度差大→胜率高）、有界（永在 0~1，不会输出 110%）、对称（$\Delta = 0$ 恰好 50%）、**可校准**（预测概率可以拿模拟频率对账）——“能力评分 87”无语义，“69%±3%”可验证；
2. **Elo 同构**：王者排位分、棋类等级分就是它的工程实现，模型外壳有 70 年统计学背书，审稿人天然信任输出格式；
3. **成熟统计性质**：最大似然估计、可扩展（Plackett-Luce 推广到排序）、参数可校准。

**novelty 所在**：传统 Elo 的强度 $s$ 从海量历史战绩统计出来（数据驱动）；这里 $s$ 从机理骨架算出来（知识驱动）——外壳是老的，内核是新的。

### 2.3 裁决模拟器（蒙特卡洛推演）

**是什么**：离散回合制抽象战斗引擎——状态机 + 结算公式（伤害/血量/CD/经济，确定性硬编码）+ 执行层随机抽样，打 N 次统计胜率。

**为什么用蒙特卡洛**：导师指出“结果空间连续，走位影响结果”——胜负不是确定值而是随机变量，**这正是蒙特卡洛成立的前提**（若确定跑一次即可）；N 次平均的估计误差为 $\mathrm{SE} = \sqrt{p(1-p)/N}$，$p \approx 0.5$、$N \approx 2000$ 时约 ±2%，故每个对阵需数千次模拟。

**随机化的三层原则（关键修正，不是全部抽象）**：
- **机制层**（CD、伤害公式、经济规则）：确定性，不许随机——随机化=篡改规则；
- **决策/状态层**（站位、开团时机）：**状态的函数 + 小噪声**——站位 $= g(\text{双方阵容},\ \text{局势}) + \epsilon$。纯随机会斩断“突进阵容→迫使抱团→克制生效”的因果链；
- **执行层**（命中偏差、走位抖动、时机误差）：随机变量，分布参数对应能力 $\lambda$。

**微策略 = 最小原则集，不是打法清单**：写 4–5 条维度完备的底层原则（目标选择/站位/交战交换比/资源收益比较），打法（如四一分推）作为“原则 × 局势”的涌现物。**克制关系在模拟器里是涌现的、在评估函数里是描述的**——模拟器不编码任何克制表。

**模拟器的资格来源**：它不学习、不拟合、不含主观权重（在某冻结版本下），所以有资格当校准的“客观参照物”；每步可审计、固定种子可复现。**注意**：模拟器经涌现验证迭代升级版本后，下游校准必须重做。

**能力参数 $\lambda$**：初始双方 $\lambda_A = \lambda_B$（锁死人的因素，量出阵容固有强弱）；之后作为显式维度变化，产出“胜率-能力曲线” $P(\text{胜} \mid \text{配置}, \lambda)$，暴露**阵容×能力交互效应**（下限队 vs 上限队）——从导师“先假设能力相同，之后分高低”自然长出的学术亮点。

**红线**：执行分布必须对称、能力差异必须显式参数化，否则模拟胜率是“阵容+操作”混合物，校准全部失效。

### 2.4 校准回路

**是什么**：挑一批阵容对 → 模拟器出胜率 → 调 $f$ 的参数（克制系数、协同权重、logistic 尺度 $\beta$）使预测对齐模拟 → 拿未参与标定的阵容对做校准曲线检验（预测 69% 的组，实际频率是否落在附近）。

**为什么**：机理参数不允许拍脑袋；模拟器是不含主观权重的参照物，校准让评估函数的每个数都有出处。

### 2.5 代理模型 + 主动模拟（方法学最大卖点）

**是什么**：用少量模拟点拟合高斯过程（GP）代理，它对任意阵容对输出“预测 + 方差”两件套；按方差/排序信息量选下一个模拟点，循环。

**为什么用 GP 而不是神经网络**：模拟点只有几百个量级，GP 在小数据上的不确定性估计是**校准的**（说 ±15% 就是真的大概 ±15%），神经网络在中小数据上过拟合且 overconfident；且 GP 的 posterior variance 天然就是主动学习需要的“没把握”度量。三个不确定度来源：① GP 预测方差（周围无数据）；② 集成分歧（多个模型打架处）；③ 模拟自身的二项噪声（当年模拟次数不够的点）。

**选点准则**：优先“两个阵容预测胜率接近但置信区间宽”的对局——最终产出是排序，这种对局一次模拟的排序信息量最大（value of information）。

**为什么必须要有代理模型**：What-if 要查询数万次，每次跑蒙特卡洛（数千局）不可行；代理模型秒级查询，优化（贝叶斯优化）才能跑在它上面。

### 2.6 What-if 分析与方案优化

在代理模型上：改配置 → 秒级重算 → 方案对比 → 贝叶斯优化找最优改动。输出三件套：胜率区间、关键因素归因（结构化模型每项可查）、改进建议。**评估只是起点，可查询可优化的代理模型才是决策价值**——这也是课题对“体系评估大脑”需求的兑现。

### 2.7 两层验证体系（课题生死线，先于一切校准）

**第一层：模拟器保真度验证**（模拟器的涌现行为可信吗）：
- 结构有效性：参数响应方向检验（加强英雄→胜率升；克制上场→被克方降）；
- 极端案例：全坦/全辅助/无控制阵容行为是否荒谬（每个荒谬行为指向一个缺失决策维度）；
- 专家盲测（face validity）：专家看模拟回放 vs 真实录像能否区分；
- 交叉验证：独立实现的另一套裁决规则重跑，排序是否稳健；
- 公开数据锚定（**待导师确认**）：公开赛事 BP+胜率只验不拟合。

**第二层：评估函数校准**（描述对齐涌现）——见 2.4。顺序不可颠倒：第一层不过关，第二层是在忠实对齐错误参照物。

**保真度阶梯与收敛判定**：L0 数值对撞 → L1 时间维度 → L2 技能机制 → L3 资源地图 → L4 微观执行（≈游戏引擎）。逐层加细节看排序 Kendall's τ 是否收敛，**停在收敛点**——“逼真度够不够”由结论稳定性定义，不由细节量定义。细化方向只沿“影响阵容相对强弱”的维度走，沿“影响体验”的维度细化就是造引擎。

**认识论定位（写论文的姿态）**：模拟器是“机理假设的显式化推演机”，不是“现实的镜子”——没有真实数据就永远无法“证明”它为真；输出读作“给定假设下的推论 + 对假设扰动的稳健性报告”。粗糙但诚实，胜过精细但无据。

## 三、被否定的路径（错误路线存档，写明理由）

| # | 被否定的做法 | 错误理由 |
| --- | --- | --- |
| E1 | **“禁一切数据驱动”红线**（原文档） | 把“训练无数据”偷换成“验证无数据”，导致闭环死亡；正确边界是“禁实际交战数据训练”，模拟数据校准与真实数据只验不拟合均合法（后者待确认） |
| E2 | **兰彻斯特方程作为聚合核心** | 假设是连续消耗战，MOBA/现代对抗是目标争夺+离散交战，机制不符；且现代战争适用性本身学界争议大；参数（损耗系数）本质是历史数据拟合，“无数据依赖”名不副实 |
| E3 | **WSC（CCF B）/ IEEE CoG（CCF C）发表规划** | 事实错误：两者均不在 CCF 推荐目录（2026 第七版核对）。正确阶梯：AAMAS（B）冲刺、ICTAI 等 C 类保底、IEEE ToG（C 类期刊）对口、CoG 仅作非 CCF 补充 |
| E4 | **“能力评分 80→87”无锚评分** | 无单位、无概率语义、不可校准不可比。替代：评分锚定为对基准阵容集的期望胜率（BT 强度值） |
| E5 | **站位/开团时机纯随机变量抽象** | 斩断“阵容构成→逼出站位→克制生效”因果链，克制关系被平均化失真。替代：决策/状态层 = 状态函数+小噪声，只有执行层纯随机 |
| E6 | **“打法清单”式微策略** | 打法无穷写不完，知识获取瓶颈无解。替代：最小原则集（4–5 条维度完备），打法涌现 |
| E7 | **逐帧引擎级模拟（L4）** | 成本超线性（L3→L4 ≈ 前三层总和）、边际信息量递减、偏离研究粒度（研究阵容级相对强弱，非操作级过程）。保序即可，无需复现 |
| E8 | **把 CVPR 当本方向学术主战场** | 数据实证：CVPR2025/2026 共 6913 篇，multi-agent 标题 36 篇（0.5%）、博弈对抗本体 2 篇、对抗 benchmark 0 篇——CV 只把多智能体当工具标签（协同感知/SLAM/LLM 编排），对抗评估本体无生态位。正确主场：AAMAS/NeurIPS/AAAI 体系 |
| E9 | **纯大模型应用层（调 API/RAG）作为就业主攻** | 供给爆炸的可替代红海，且算力受限连 baseline 都跑不动。替代：以“无真值评估方法论”切入大模型行业评测岗（腾讯 Agent 评测 JD、AGI-Eval 招游戏评测均为实证），差异化竞争 |
| E10 | **用监督学习拟合历史对局胜率（外部文献主流做法）** | 违反课题红线。但**保留为实验对照组**——论文必须与数据驱动基线对比才能成立（这是它唯一合法出场方式） |
| E11 | **“六七个应用领域全做”**（无人集群/机器人/工业/作战全上） | 范围爆炸，六个都做浅。实验场只定游戏阵容（可验证、可复现、可锚定），其余进 future work |

## 五、明确“不知道/待确认”事项（诚实清单）

1. **公开赛事数据能否用于验证**——取决于导师对“校准≠拟合”边界的认可度，需当面确认；若否，退化为①-④道验证关 + 专家盲测，科学性下降但可接受；
2. **最小原则集的具体内容**——无法预先穷尽，靠“分类学对照 + 极端阵容自测 + 行为统计监控”的调试循环补全（规则系统是调试出来的，不是设计出来的）；
3. **机制类克制划分的最优粒度**（10 类还是 20 类）——需实验确定，粒度是自由参数；
4. **保真度阶梯的收敛点位置**（L2 还是 L3 停）——实证决定，无法先验；
5. **AAMAS 对此类工作的实际接受率**——无公开分赛道统计，20–25% 是全会估计，对本类工作仅作参考；
6. **模拟器版本升级后的校准失效半径**——每次改规则需重跑多大范围的校准集，需实践确定；
7. **β 尺度参数的校准精度上限**——依赖模拟器保真度，模拟器错则 β 错。

## 六、发表与就业主线（结论存档）

**发表阶梯**：IEEE CoG / ToG（对口、练手）→ **AAMAS（CCF B，主目标）** → AAAI/IJCAI 应用 track（冲刺）；叙事框架统一为“**有限仿真预算下的组合对抗体系可解释评估方法**”，游戏与军事均为应用案例。

**就业定位**：技能树 = 蒙特卡洛仿真 + 贝叶斯评估 + 不确定性量化 + 多智能体 + 系统集成；出口 = 大模型行业**评测岗**（差异化入口）、游戏数值/AI、自动驾驶仿真评估、数字孪生；军工资源用于研究与验证场景，不用于职业身份。简历语言必须是方法论关键词，不是“王者荣耀胜率系统”。

砍掉不做：L3 地图资源（除非验证发现是胜负手）、L4 微观、花哨前端。风险备案：最大风险是模拟器涌现质量，对策是早 sanity check、小步迭代；算力零依赖（CPU 为主）。

**一页话总结**：这个课题 = **把导师脑中的机理知识，变成一台可运行、可审计、可批驳的推演仪器；用仪器当标准答案校准一个带概率语义的评估函数；用主动模拟把钱花在刀刃上；用两层验证回答“凭什么信你”**。方向上，技能通用（CVPR 数据证明 multi-agent 在涨）、场景专用（对抗评估本体在 CV 无生态位）——所以保留技能、去掉场景专用性，军工资源当研究燃料，民用评测当职业出口。
