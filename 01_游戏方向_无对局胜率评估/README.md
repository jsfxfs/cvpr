# 01 · 游戏方向：无对局数据条件下组合对抗体系的胜率评估

## 一句话

在**没有任何真实对局数据**的条件下，对任意给定的 5v5 阵容对输出：带置信区间的胜率、优势归因、候选池内排序与改进建议。方法本体 = 结构化评估函数（机理骨架）＋ 裁决模拟器（冻结参照物）＋ 残差 GP 代理（主动模拟分配预算）＋ 两层验证体系。

## 审核报告的 9 条修正去向（v3 已全部落地）

BT 标量差式 → 成对 logit（+不可传递性诊断）；校准叙事 → surrogate/metamodel + VV&A；"客观参照物" → "冻结、可审计、可复现"；GP 叙事 → 机理先验压缩 + 残差光滑性前置实验；专家盲测 → 统计指纹比对 + 行为模式审查；相关工作补三条邻近谱系；排序产出限定候选池；表述降调；勘误修正。
