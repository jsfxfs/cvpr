## 论文信息

- **标题**：System-of-systems effectiveness evaluation of UAV swarm: A data-driven perspective
- **作者**：Wei Quan, Chen Chen, Fang Deng, Bin Xin（北京理工大学自动化学院 / 自主智能无人系统全国重点实验室）
- **期刊**：Chinese Journal of Aeronautics, 2026, 39(8): 103848（2025-04-30 投稿，2025-08-28 录用，2025-09-28 在线）
- **DOI**：10.1016/j.cja.2025.103848

## 方法要点

1. 系统指标经二维循环堆叠（two-dimensional loop stacking）变换后，用残差网络建立"体系指标 → 效能"的评估网络；
2. 针对效能评估中的高估问题，设计偏斜损失函数（skewed loss）在训练中抑制高估；
3. 训练数据依赖耗时的仿真标注，故设计**基于聚类迭代 + 随机贪心采样的主动学习策略**，用有限高价值样本维持模型精度。

## 与本工作区的关系

- 它是"体系效能评估"方向的代表作，对应本项目早期"无人机集群/军工体系评估"的选题背景；
- 其"**有限仿真预算 + 主动选样**"的思路与原 01 线（"零真实数据 + 机理驱动 + 主动模拟"）同源；01 线已于 2026-09 转向"公开数据（Dota 2）+ GNN"，本文及 `相关论文_两篇.md` 可作为同范式（仿真数据 + 学习式评估）的定位参考与对照组素材。
