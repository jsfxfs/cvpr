# 方向选择最终分析 v2.1（修订版）：3DGS/3D 线 vs 大模型线

> 日期：2026-09-09（v2.1 修订）
> **本版相对 v1 的四处实质修正**：
> 1. **约束模型重写**：原把"不做前馈式"理解为全面排除是错的。实际约束只是"从零训练算力不够"——**拿现成通用模型微调完全可以**；"不了解的领域"只是学习成本，不是禁区。这解锁了一条 v1 漏掉的强候选方向（专题 B）。
> 2. **RAG 方向重新质证**：针对"RAG 是否已水/被长上下文替代"做了专项查证（专题 A），结论是角度决定生死，主攻角度相应升级。
> 3. **总推荐更换**：主攻从"多模态 RAG"改为"通用前馈 3D 模型微调/域适配"，RAG 降为并列主攻（就业宽度优先时选它）。
> 4. **补齐其他方向全扫描（专题 C）**：v1/v2 只深查了两条主线，其余方向仅按约束粗排。v2.1 用第三轮本地统计（`niche_probe3.py`）把主线外所有子方向逐一过了一遍，给出逐条判决——哪些被硬约束挡掉、哪些被数据证实饱和、哪些在涨但性价比不够、哪些其实已被两条主线吸收。
>
> 依据：① 本地 CVPR 2025/2026 全量统计（`niche_probe.py`、`niche_probe2.py`、`niche_probe3.py`）；② 两轮联网查证（RAG 替代风险、前馈模型微调可行性）；③ 此前趋势报告与三路调研。

| 定位 | 方向 | 一句话理由 |
| --- | --- | --- |
| **主攻（默认推荐）** | **通用前馈 3D 重建模型（VGGT/DUSt3R/MVSplat 系）的微调与域适配**，切入点：不确定性估计 或 低纹理/弱纹理域适配 | 约束修正后与你匹配度最高：组积累 100% 复用、算力完美适配（12M 的 MVSplat 可全参微调、1.2B 的 VGGT 可 LoRA）、方向早中期且有明确空白、几何评测客观不易被嫌水 |

## 二、专题 A：RAG 到底水不水——查证结论

### A.1 你的判断对的一半

1. **朴素 RAG 确实变水了**：查证确认，"换个 chunking/reranker 涨 1–2%、无消融、不对比长上下文、无成本分析"的论文在 2025–2026 会被审稿人直接判水。
2. **长上下文确实替代了一部分场景**：单文档问答、小语料、不计成本的任务。Google 的 Self-Route 研究显示：资源充足时长上下文平均效果优于 RAG [$TRAE_REF](https://arxiv.org/pdf/2407.16833v2.pdf)。

### A.2 你的判断不对的一半

1. **长上下文替代不了 RAG 的五个硬场景**：推理成本（长上下文注意力开销远高于检索片段）、知识时效性（更新索引 vs 重训/重写 prompt）、权限隔离（行级过滤）、超大语料（超出任何上下文窗口）、可审计性（检索证据链）。Self-Route 本身的结论就是"混合路由"而非"RAG 已死"。
2. **长上下文自身有硬伤**："Lost in the Middle" 证明 LLM 对长上下文中部信息的利用率显著下降（U 形曲线），多模型普遍存在 [$TRAE_REF](https://arxiv.org/html/2307.03172v1)。
3. **本地数据**：CVPR 语料里"长上下文"提及量一年仅 +16%（低于大盘 +40.8%），而"检索"整体 +70%、RAG +192%——至少在视觉社区，检索在扩张、长上下文没有碾压。
4. **工业界仍在大规模用**：向量数据库市场年增约 23.5%；中国 RAG 市场 2025 年约 480 亿元、同比 +67.8%；华为等公司的 RAG 岗 JD 要求已升级为"管线工程 + 评测体系 + agentic retrieval"——岗位在，要求变高了。

### A.3 结论：能做与不能做的分界线

| 能做出成果的角度 | 做不出成果的角度 |
| --- | --- |
| 多模态 RAG 的系统评测 + 失败分析（文档/图表/长视频场景） | "我又换了一个 chunking/reranker，涨了 2%" |
| RAG 可靠性 / 检索幻觉（检索到误导信息时如何保持忠实） | "我搭了一个某领域 RAG 系统"（无系统评估） |
| Agentic RAG 的评测与优化（查询重构、停止条件、跳数控制） | 只单数据集、无消融、不对比长上下文 |
| RAG vs 长上下文的成本-收益路由（Self-Route 的场景化延伸） | 无成本分析（token/延迟/存储） |

**一句话**：RAG 没死，死的是"RAG 水论文"。做评测/可靠性角度能出成果且就业技能完全对口；做管线微调角度确实出不了成果。

## 三、专题 B：通用前馈 3D 模型微调——被约束修正解锁的方向

### B.1 算力可行性（查证 + 本地数据交叉确认）

| 模型 | 规模 | 3×3090 上的微调可行性 |
| --- | --- | --- |
| MVSplat | ~12M | **全参微调都轻松**（显存 <1GB 级），性价比最高的实验平台 |
| CUT3R | ~463M | LoRA/冻结 backbone 微调可行 |
| DUSt3R / MASt3R | ~571M | LoRA/部分层微调可行，多视图时注意显存 |
| VGGT | ~1.2B | **全参不可行，LoRA/部分层微调可行**；已有 8GB 显存推理 150 图的开源实现，推理侧零压力 |

结论：这条线对你的算力**完全开放**。路线建议：用 MVSplat 做快速方法验证（全参、迭代快），确定方法后迁移到 DUSt3R/VGGT 上做 LoRA 验证泛化性——"小模型验证 + 大模型背书"是这类论文的标准结构。

### B.2 领域现状：早中期，局部已挤

- 本地统计：VGGT 被提及 1→39 篇（一年），"前馈重建 + 微调/适配/测试时"组合 55→78（+42%），"前馈 + 不确定性" 9→16（+78%）。
- 已成型的主线：Fin3R（NeurIPS 2025，知识蒸馏微调 3R 系模型）、ZipMap（CVPR 2026，test-time training）、Scal3R（CVPR 2026，大场景 TTT）、AdaptSplat（1.5M adapter 适配）、RayTun3R（在线相机校准适配）、Fisheye3R（鱼眼适配）、Cross3R（跨视角遥感）。
- **警告：VGGT 的 token 压缩/加速细分已挤**——仅 CVPR 2026 一年就有 HTTM、LiteVGGT、AVGGT、FlashVGGT、Co-Me 五篇以上做同类工作，不要进这个缝。

### B.3 可切入的空白（查证确认，按推荐度排序）

1. **前馈重建的不确定性估计**：主流通用模型直接吐点云/深度/位姿，没有可量化的不确定度，下游（SLAM 闭环、主动视角选择、编辑）没法用。切入点：给 VGGT/DUSt3R 的输出加置信度建模 + 校准评测 + 一个下游应用（如不确定度引导的主动补拍/视角选择）。本地该细分 +78% 且基数小，正处窗口期。
2. **低纹理/弱纹理域适配**：室内纯色墙、工业产线、无纹理物体——通用模型几何退化严重。切入点：LoRA 域适配 + 合成数据/伪标签。组里做三维重建，这类场景数据不难造。
3. **特殊模态适配**（红外/事件相机/深度+RGB）：公开适配工作少，但需要对应数据源，先确认数据再定。

### B.4 为什么它适合你（逐条）

1. **组积累复用 100%**：全组做三维重建，代码、数据、师兄师姐的领域知识全部用得上——对研一学生，这是最大的风险对冲。
2. **论文形态稳健**：几何评测（位姿/深度误差 + 校准曲线）客观硬指标，不存在"被嫌水"的问题；对比基线（原版通用模型）现成。
3. **学习成本可控**：需要学的是 DUSt3R/VGGT 代码库（2–4 周）+ LoRA 微调（你已会）+ 不确定性量化方法（数周补课）。你说过方向合适就学——这就是那个"合适"的方向。
4. **就业不虚**：3D 重建/数字孪生/AR/驾驶感知岗的 JD 明确要这类技能（Matterport、PICO、Adobe、NVIDIA 均有对口岗位）；且"微调过十亿级几何基础模型 + 做过评测体系"的叙事可以平移到空间智能/多模态岗位。
5. **与你导师那条线的方法论暗合**：不确定性量化、置信区间、校准——这些你在导师项目里耳濡目染的东西在这里直接是核心技术。

## 七、总推荐与理由

**默认推荐：主攻"通用前馈 3D 模型微调/域适配（不确定性估计切入）"，保底 3DGS 水印/质量评估；若你明确把就业面宽度放第一位，主攻换成"多模态 RAG × 评测/可靠性"。**

为什么默认推荐从前馈微调而不是 RAG（尽管 RAG 就业更宽）：

1. **风险结构**："水一篇"的第一原则是别孤军作战。前馈微调线你背后是整个组的三维重建积累（代码/数据/经验）；RAG 线你在组里是单点，没人能帮你审稿级地把关。
2. **论文稳健性**：几何评测是硬指标，审稿争议小；RAG 论文正面临审稿人疲劳，必须靠更重的 benchmark 设计自证不水——同样的时间预算，前者下限更高。
3. **你的直觉信号**：你主动质疑 RAG 的水度，说明你对它信心不足；而对"微调通用模型"这条路你主动纠正了我的过度限制——兴趣所在的地方，执行力通常更好。
4. **就业并没有真正牺牲**：3D 基础模型微调技能对空间智能/多模态岗位可迁移；且保底方案与求职三件套（开源/博客/实习）照常执行。

**两条主攻线可以低成本并行试跑**：前 6 周同时搭 MVSplat 微调最小回路（前馈线）和 Qwen-VL + 检索的最小多模态 RAG 回路（RAG 线），第 6 周用"哪条线先跑出可复现基线 + 你更想做哪个"双标准定夺。总有一条在 2027-03 前够得着 ICCV/CVPR workshop 窗口。
