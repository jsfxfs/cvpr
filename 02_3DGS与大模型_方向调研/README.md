# 02 · 3DGS 与大模型方向调研（基于 CVPR 全量统计）

## 一句话

用本地爬取的 CVPR 2025/2026 全量论文数据（2871 + 4042 篇）做定量方向筛查，从 25 个主方向 / 39 个子方向中收敛出"两条主线 + 一个保底"。

## 文件说明

| 文件 | 角色 |
| --- | --- |
| `CVPR趋势分析与研究方向选择完整报告.md` | 趋势底稿：2025/2026 各方向详解、跨年对比、修正清单、前馈式 3DGS 与测试时方法两个专题、决策矩阵 |
| `方向选择_3DGS与大模型_最终分析.md` | **决策结论（v2.1）**：约束模型三档、RAG 专题质证、前馈微调专题、主线外全扫描、推荐排序与时间线 |
| `定向统计/niche_probe.py` → `niche_probe_results.json` | 第一轮：3DGS 家族与大模型家族细分方向命中统计（2025 vs 2026） |
| `定向统计/niche_probe2.py` → `niche_probe2_results.json` | 第二轮：长上下文 vs RAG、VGGT/DUSt3R 系提及量、前馈+微调/不确定性交叉统计 |
| `定向统计/niche_probe3.py` → `niche_probe3_results.json` | 第三轮：主线外 39 个子方向全扫描（专题 C 依据） |
| `定向统计/niche_show*.py` | 结果查看器：打印各方向 2026 年论文标题样本 |

## 结论摘要（详见最终分析）

- **主攻（默认）**：通用前馈 3D 重建模型（VGGT/DUSt3R/MVSplat 系）的微调与域适配，切入点：不确定性估计 或 低纹理域适配；
- **并列主攻（就业宽度优先）**：多模态 RAG × 评测/可靠性（禁止做朴素管线改进）；
- **保底**：3DGS 水印/安全 或 3DGS 质量评估；
- **明确不做**：NeRF、从零预训练大模型、朴素 RAG 水线、VGGT token 压缩/加速、GRPO 后训练（非首选）。

## 使用方法

脚本按自身位置自动定位语料（`../../05_CVPR数据与工具/`），在本目录或任意目录执行均可：

```bash
python 定向统计/niche_probe3.py     # 重跑第三轮统计，覆盖同目录 results.json
python 定向统计/niche_show3.py      # 查看关键方向 2026 年标题样本
```

语料结构与爬虫复现见 `../05_CVPR数据与工具/README.md`。
