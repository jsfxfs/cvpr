## 利用GitHub Issues + Project + Dashboard自我驱动

### Projects

我将整个知识体系分为多个章节，主要包含章节内容及体系相关性内容:

- 知识体系主题相关
- 平时一闪而过的Idea
- 章节内容 - 如: 数据结构

![](https://www.pdai.tech/images/blog/blog-stack-3.png)

一些内容在看总结之前会先阅读大量相关的文章，并梳理主要的知识点，然后写进知识主题相关的Project；继而在VS Code 中创建相关的章节。

### Issues

在创建相关的Project之后，会将上述梳理知识章节创建Issues，用于Followup自己的进度。

![](https://www.pdai.tech/images/blog/blog-stack-4.png)

### Kanban

对Issues按照Project为切面，用敏捷看看板的方式纵览完成情况。

![](https://www.pdai.tech/images/blog/blog-stack-5.png)
