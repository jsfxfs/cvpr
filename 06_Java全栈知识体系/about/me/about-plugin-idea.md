# 关于 - pdai.tech IDEA插件

> 本文主要介绍pdai.tech IDEA插件，以及插件的使用和后续更新的计划；同时也开放了讨论，如果对插件使用和拓展有任何建议，可以在评论区域留言。@pdai

## 插件简介

> 很多读者期望在开发中方便**系统性**的学习，并且**在开发过程**中利用上**闲暇碎片化时间**，那么将开发者可以在如下场景使用这个插件：

- 在代码编译等待期间，利用碎片化的实践进行学习
- 在工作闲暇时，可以摸鱼学习，你可以把它当做一个**摸鱼神器**
  - 摸鱼时也考虑了你的隐私性，屏幕缩小时不会显示《Java 全栈知识体系》几个大字
- 在遇到问题时，直接在网站中进行搜索
- 在需要使用常见的工具时，可以直接使用网站的工具和导航
- ...

## 使用说明

> 当前插件对IDEA的版本有要求，目前支持的版本是 社区版本/商业版本，2021.3.3及以上版本。

### 插件的安装

打开Settings配置，点击Plugins的配置项，在market中搜索 “pdai”

![](https://www.pdai.tech/images/blog/blog-plugin-1.png)

### 插件的使用

插件的使用比较简单，直接打开右侧工具栏即可

![](https://www.pdai.tech/images/blog/blog-plugin-2.png)

点击【导航相关按钮】可以像浏览器一起导航

![](https://www.pdai.tech/images/blog/blog-plugin-3.png)

点击【Zoom相关按钮】可以放大缩小页面

![](https://www.pdai.tech/images/blog/blog-plugin-4.png)

双击顶部，可以放大查看这个网页内容

![](https://www.pdai.tech/images/blog/blog-plugin-6.png)

可以将tab拖拽到下方工具栏

![](https://www.pdai.tech/images/blog/blog-plugin-5.png)
