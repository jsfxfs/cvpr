# 正则表达式 - 在线工具汇总

> 本文主要总结常用的在线正则表达式相关的工具，从而高效的写出正确的表达式。@pdai

## 工具一：可视化理解正则

> 该工具主要帮助你理解你的正则表达式

- [正则表达式工具-Regulex](https://jex.im/regulex)
- 以 **正浮点数** 为例子：`^[1-9]\d*\.\d*|0\.\d*[1-9]\d*|0?\.0+|0$`, 你将可以非常直观的看到它的流程：
