## 两条候选主线的关系

- **01 游戏方向**：导师类比落地后的路线——"王者荣耀 5v5 阵容看属性判胜率、大量模拟求概率、不用真实对局数据训练"。当前已有 v3 定稿（标准版 + 通俗版）、20 分钟导师汇报大纲和一份独立审核报告。
- **02 3DGS/大模型方向**：用本地爬取的 CVPR 全量数据做的定量方向筛查。默认推荐"通用前馈 3D 模型微调（不确定性估计切入）"，并列主攻"多模态 RAG × 评测/可靠性"，保底"3DGS 水印/质量评估"。
- 两条线**互不冲突**：02 的原文建议是前 6 周各跑一个最小基线再定夺；01 则有明确的 Phase 0–4 路线图。

## 复现与维护约定

- **CVPR 数据**：在 `05_CVPR数据与工具/` 下执行 `conda run -n scrapling python run_cvpr.py --years 2026 --skip-abstracts` 重跑分类；详见该目录 README。
- **定向统计**：`02_3DGS与大模型_方向调研/定向统计/` 下三个 `niche_probe*.py` 脚本按自身位置自动定位语料，任意目录直接 `python niche_probe3.py` 即可运行，结果写回脚本同目录。
- **HTML 资料**：`03_MODAF调研/modaf-study/` 与 `01_.../审核报告/` 两个页面依赖各自的 `_shared/`、`assets/` 子目录，移动时请整体移动。
- **新增文件**：请放进对应的 `0X_` 目录；脚本不要写死绝对路径（本次整理已把 `niche_probe*.py` 的绝对路径改为按脚本位置定位）。
- **git 提交**：本次整理只移动了文件、未做任何提交；需要入库时 `git add -A` 即可（Git 会自动识别为重命名）。
