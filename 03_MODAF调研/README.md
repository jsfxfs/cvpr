# 03 · MODAF 调研（课题组口头介绍材料）

## 是什么

针对课题组"命题作文"准备的调研材料，主题为 **MODAF（英国国防部体系结构框架，Ministry of Defence Architecture Framework）**，并附 DoDAF / MODAF / UAF / Palantir 四题总览与演进全景。

## 两篇文档，建议按顺序读

| 文件 | 定位 | 什么时候看 |
| --- | --- | --- |
| `modaf-study/modaf-study-白话版.html` | **白话入门**：不背术语、不堆缩写，先讲"为什么会有它"，再用生活类比讲透三个核心想法（视角/视图、数据为中心、元模型），最后给速记卡和"最容易讲错的几句话" | **先看这篇**，约 15 分钟建立整体印象 |
| `modaf-study/modaf-study.html` | 详细版（原版）：细节、出处、46 张视图完整清单、与 DoDAF 的逐条差异、英国国防术语词典、15 分钟叙事线、8 个问答预案、10 条概念红线 | 白话版看完后补细节；临场前当应答手册 |

> 两篇在页内互相链接；详细版顶部有"先看白话版"的提示。

## 白话版的内容结构（`modaf-study-白话版.html`）

1. 三十秒版本：一句话说清它是什么（含三个"不是"）；2. 它要解决的问题：四个"老大难"（各说各话/重复买/项目互相拖/图纸对不上）；3. 核心就三个想法；4. 七个视角：七类人七个问题；5. 它和美国版 DoDAF 差在哪；6. 它的一生（2005→2010→2021 退役）；7. 退役了为什么还值得了解；8. 最容易讲错的几句话；9. 上桌速记卡；10. 去看详细版的哪一节。

## 详细版的内容结构（`modaf-study.html`）

1. 四个题目之间的关系；2. MODAF 一句话定位与官方定义；3. 历史与版本（2005–2010）；4. 视角、视图与"数据为中心"；5. 七大视角与全部视图清单（重点）；6. MODAF 与 DoDAF 的区别；7. 英国国防背景小词典；8. 生态与现状（MODAF → NAF / UAF）；9. 口头介绍实战：叙事线、比喻与问答预案；附参考来源。

## 使用方式

- 浏览器直接打开即可（两篇均为单文件 HTML，图表用 Mermaid 本地渲染，离线可用）；
- 页面依赖 `modaf-study/_shared/`（字体、mermaid.min.js）与 `modaf-study/assets/`（mermaid 初始化），**移动时请整体移动该目录**。
